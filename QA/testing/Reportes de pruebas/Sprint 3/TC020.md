## Objetivo

Verificar el flujo completo de una donación desde el frontend, pasando por Caddy y APISIX, hasta el servicio de donaciones y su persistencia en la base de datos.

## Precondiciones

* Plataforma RedVital disponible en ambiente de pruebas.
* Caddy, APISIX y los servicios de RedVital activos.
* Bases de datos disponibles.
* Usuario operador habilitado para registrar donaciones.

## Pasos de prueba

| Paso | Acción                                                          | Resultado esperado                                                                                                      |
| ---- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1    | Iniciar sesión como operador de banco de sangre.                | El usuario accede correctamente al sistema.                                                                             |
| 2    | Ingresar al flujo de registro de donación.                      | El formulario de donación se encuentra disponible.                                                                      |
| 3    | Registrar una donación con datos válidos.                       | La solicitud es procesada correctamente.                                                                                |

| 6    | Consultar la base de datos de donaciones.                       | La donación registrada se encuentra persistida.                                                                         |
| 7    | Consultar las unidades asociadas.                               | Se encuentran las unidades generadas por la donación y la información coincide con el resultado mostrado en el sistema. |
