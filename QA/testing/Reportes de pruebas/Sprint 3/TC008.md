| Título                           | Registro de auditoría de operaciones realizadas |
| Historia o requisito relacionado | `EC-33 / T-311.2`                               |

| Prioridad                        | `Alta`                                          |

| Versión                          | `0.1`                                           |

## Objetivo

Verificar que las operaciones realizadas por un usuario sean registradas correctamente en el mecanismo de auditoría, identificando el actor, rol, operación, recurso y resultado.

## Precondiciones

* El ambiente de pruebas se encuentra desplegado y operativo.
* Existe un usuario operador autenticado.
* Se ha realizado una operación de registro de donación.
* La base de datos de donaciones se encuentra disponible para consultar los registros de auditoría.

## Datos de prueba

| Dato               | Valor o referencia   |
| ------------------ | -------------------- |
| Rol                | `operador`           |
| Operación          | `registrar_donacion` |
| Recurso            | `donacion`           |
| Resultado esperado | `permitido`          |
| Fecha de operación | `2026-10-08`         |

## Pasos de prueba

| Paso | Acción                                                                     | Resultado esperado                                                                            |
| ---- | -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| 1    | Realizar una operación de registro de donación como usuario operador.      | La operación se ejecuta correctamente.                                                        |
| 2    | Consultar la tabla `registro_auditoria` de la base de datos de donaciones. | La operación realizada aparece registrada.                                                    |
| 3    | Verificar el actor, rol, operación, recurso y resultado del registro.      | Los datos de auditoría corresponden con la operación realizada y el resultado es `permitido`. |
