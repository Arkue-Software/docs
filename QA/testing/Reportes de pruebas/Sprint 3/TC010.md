# Caso de prueba - TC-010

## Información del caso de prueba

| Campo                            | Información                                 |
| -------------------------------- | ------------------------------------------- |
| Identificador                    | `TC-010`                                    |
| Título                           | Idempotencia en el registro de una donación |
| Historia o requisito relacionado | `EC-10`                                     |
| Tipo de prueba                   | `Funcional / Integración`                   |
| Prioridad                        | `Alta`                                      |
| Autor                            | `Tomás`                                     |
| Versión                          | `0.1`                                       |

## Objetivo

Verificar que una misma operación de registro de donación no pueda procesarse nuevamente utilizando el mismo código, evitando la creación de donaciones o unidades duplicadas.

## Precondiciones

* El ambiente de pruebas se encuentra desplegado y funcional.
* Existe un usuario con permisos de operador de banco de sangre.
* El operador puede registrar donaciones.
* Existe un código de donación válido para realizar la operación.

## Datos de prueba

| Dato                         | Valor o referencia            |
| ---------------------------- | ----------------------------- |
| Código de donación           | `8YBX-7464-PJE9`              |
| Operación                    | `registrar_donacion`          |
| Código de respuesta esperado | `201` en la primera operación |

## Pasos de prueba

| Paso | Acción                                                                | Resultado esperado                                                                                                  |
| ---- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 1    | Iniciar sesión como operador de banco de sangre.                      | El usuario accede correctamente al sistema.                                                                         |
| 2    | Seleccionar la opción para registrar una donación.                    | Se muestra el formulario de registro.                                                                               |
| 3    | Completar los datos requeridos para la donación.                      | Los datos son aceptados por el sistema.                                                                             |
| 4    | Ingresar el código de donación válido.                                | El sistema verifica que el código existe y permite continuar.                                                       |
| 5    | Enviar la donación.                                                   | La donación se registra correctamente y se genera el código `8YBX-7464-PJE9`.                                       |
| 6    | Intentar realizar nuevamente la operación utilizando el mismo código. | El sistema impide reutilizar el código y rechaza la operación duplicada.                                            |
| 7    | Consultar la tabla `operacion_idempotente` en la BD.                  | Se encuentra registrada la operación `registrar_donacion` con código de estado `201`.                               |
| 8    | Consultar la tabla `donacion` en la BD.                               | Se encuentra la donación original sin evidenciar una segunda donación generada por el reintento.                    |
| 9    | Consultar la tabla `unidad` en la BD.                                 | Se encuentran las unidades correspondientes a la donación original, sin unidades duplicadas producto del reintento. |
