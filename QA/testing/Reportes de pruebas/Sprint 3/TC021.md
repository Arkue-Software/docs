| Título                           | Coherencia de datos sintéticos entre las tres bases |
| Historia o requisito relacionado | `HU-302`                                            |

## Objetivo

Verificar que los datos sintéticos utilizados en las bases de datos de RedVital mantengan identificadores coherentes, no contengan información de causa clínica y sean cargados mediante las semillas definidas para el ambiente de pruebas.

## Precondiciones

* Ambiente QA disponible.
* Bases de datos de identidad, donación y campañas disponibles.
* Semillas sintéticas de QA disponibles.
* Contenedores de datos iniciados correctamente.

## Datos de prueba

| Dato                             | Valor o referencia                          |
| -------------------------------- | ------------------------------------------- |
| Semilla de identidad             | `secretos/qa/semilla_identidad.sql`         |
| Usuarios sintéticos de identidad | 6                                           |
| Usuarios adicionales de prueba   | 1                                           |
| Jurisdicciones                   | 6                                           |
| Bases verificadas                | `db_identidad`, `db_donacion`, `db_campana` |

## Pasos de prueba

| Paso | Acción                                                                                  | Resultado esperado                                                         |
| ---- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 1    | Verificar la existencia de las semillas sintéticas de QA.                               | Las semillas requeridas se encuentran disponibles.                         |
| 2    | Verificar que `semilla_identidad.sql` sea utilizada durante el despliegue de datos.     | El `docker-compose` de datos referencia la semilla.                        |
| 3    | Consultar los usuarios cargados en `db_identidad`.                                      | Los usuarios sintéticos definidos en la semilla se encuentran registrados. |
| 4    | Verificar las relaciones entre los datos de donación, donantes, intenciones y campañas. | No existen registros huérfanos en las relaciones verificadas.              |
| 5    | Buscar campos relacionados con causa clínica, diagnóstico o enfermedad en el esquema.   | No existen columnas con estos conceptos.                                   |
| 6    | Verificar la idempotencia definida en las semillas.                                     | Las inserciones utilizan mecanismos `ON CONFLICT` para evitar duplicados.  |
