## Objetivo

Verificar que los componentes de la plataforma RedVital puedan iniciarse correctamente después de un arranque completo, manteniendo disponibles las bases de datos, servicios, gateway y frontend.

## Precondiciones

* Docker Desktop disponible y funcionando.
* Archivos de configuración del ambiente QA disponibles.
* Contenedores de RedVital detenidos previamente para realizar un arranque completo.
* Ambiente configurado como `Pruebas`.

## Datos de prueba

| Dato                    | Valor o referencia                                         |
| ----------------------- | ---------------------------------------------------------- |
| Ambiente                | `Pruebas`                                                  |
| Configuración           | `qa.env`                                                   |
| Componentes verificados | Bases de datos, servicios, Kafka, APISIX, Caddy y frontend |

## Pasos de prueba

| Paso | Acción                                                    | Resultado esperado                                                                  |
| ---- | --------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 1    | Iniciar los componentes de datos mediante Docker Compose. | Las tres bases de datos inician correctamente y alcanzan estado saludable.          |
| 2    | Iniciar los servicios de RedVital.                        | Los servicios de identidad, campañas y donaciones inician correctamente.            |
| 3    | Iniciar los componentes de borde.                         | APISIX y Caddy quedan disponibles.                                                  |
| 4    | Verificar el estado de los contenedores.                  | Los componentes principales quedan activos y los servicios con healthcheck exitoso. |
| 5    | Acceder al sistema y verificar su disponibilidad.         | El frontend y los servicios principales pueden utilizarse correctamente.            |
