# Caso de prueba - TC-011

## Información del caso de prueba

| Campo                            | Información                           |
| -------------------------------- | ------------------------------------- |
| Identificador                    | `TC-011`                              |
| Título                           | Aislamiento ante fallo de un servicio |
| Historia o requisito relacionado | `EC-08`                               |
| Tipo de prueba                   | `Integración`                         |
| Prioridad                        | `Alta`                                |
| Autor                            | `Tomás`                               |
| Versión                          | `0.1`                                 |

## Objetivo

Verificar que la indisponibilidad de un servicio no afecte el funcionamiento de los demás servicios de la aplicación y que el servicio afectado pueda recuperarse correctamente.

## Precondiciones

* El ambiente de pruebas se encuentra desplegado y funcional.
* Todos los servicios se encuentran activos.
* Campaign Service se encuentra disponible.
* APISIX y Caddy se encuentran funcionando correctamente.
* Las funcionalidades de campañas y unidades se encuentran disponibles.

## Datos de prueba

| Dato                        | Valor o referencia                                                        |
| --------------------------- | ------------------------------------------------------------------------- |
| Servicio afectado           | `campaign-service`                                                        |
| Funcionalidad               | Consulta de campañas/jornadas                                             |
| Funcionalidad independiente | Consulta de unidades                                                      |
| Código esperado             | `502` para campañas durante la caída; `200` para servicios independientes |

## Pasos de prueba

| Paso | Acción                                                          | Resultado esperado                                                                                |
| ---- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 1    | Verificar que los servicios se encuentren activos.              | Los servicios aparecen activos y funcionales.                                                     |
| 2    | Detener `campaign-service`.                                     | El servicio se detiene sin afectar los demás contenedores.                                        |
| 3    | Consultar campañas/jornadas desde la aplicación.                | La funcionalidad de campañas deja de estar disponible debido a la caída del servicio dependiente. |
| 4    | Consultar unidades desde la aplicación.                         | Las unidades continúan funcionando correctamente.                                                 |
| 5    | Realizar una operación de autenticación o renovación de sesión. | El servicio de identidad continúa funcionando correctamente.                                      |
| 6    | Revisar los logs de APISIX.                                     | APISIX permanece activo y registra el fallo de conexión únicamente hacia `campaign-service`.      |
| 7    | Iniciar nuevamente `campaign-service`.                          | El servicio vuelve a estar disponible.                                                            |
| 8    | Consultar nuevamente campañas/jornadas.                         | Las campañas vuelven a funcionar correctamente.                                                   |
