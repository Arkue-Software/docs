# Caso de prueba - TC-006M

| Campo                            | Información                                          |
| -------------------------------- | ---------------------------------------------------- |
| Identificador                    | `TC-006M`                                            |
| Título                           | Control de acceso entre instituciones sobre unidades |
| Historia o requisito relacionado | `EC-39 / H-04`                                       |
| Tipo de prueba                   | `Seguridad`                                          |
| Prioridad                        | `Alta`                                               |
| Autor                            | `Tomás`                                              |
| Versión                          | `0.1`                                                |

## Objetivo

Verificar que un operador perteneciente a una institución no pueda acceder a la información de unidades que se encuentran bajo custodia de otra institución.

## Precondiciones

* El ambiente de pruebas se encuentra desplegado y operativo.
* Existe un usuario operador asociado a la institución A.
* Existe una unidad asociada a la institución B.
* El usuario operador cuenta con una sesión autenticada mediante token de acceso.
* La unidad utilizada para la prueba es `0102f457-cdbd-4cd7-b181-cb21ab4612a8`.

## Datos de prueba

| Dato                     | Valor o referencia                      |
| ------------------------ | --------------------------------------- |
| Usuario                  | `operador@redvital.test`                |
| Institución del usuario  | Institución A                           |
| Institución de la unidad | Institución B                           |
| Unidad                   | `0102f457-cdbd-4cd7-b181-cb21ab4612a8`  |
| Operación                | `GET /api/v1/unidades/{unidad}/eventos` |

## Pasos de prueba

| Paso | Acción                                                               | Resultado esperado                                                                             |
| ---- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1    | Iniciar sesión como `operador@redvital.test`.                        | Se obtiene un token de acceso válido para el operador de la institución A.                     |
| 2    | Solicitar los eventos de la unidad perteneciente a la institución B. | El sistema debe impedir el acceso a información fuera del alcance institucional del usuario.   |
| 3    | Revisar la respuesta de la API.                                      | No se deben retornar los eventos ni información de la unidad perteneciente a otra institución. |
