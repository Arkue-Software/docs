# Informe de evaluación del Sprint [Número]

> **Instrucciones de uso - eliminar al crear un informe real:**  
> Esta plantilla se utiliza una vez finalizado cada Sprint para registrar y evaluar, con evidencia, el cumplimiento del objetivo, las tareas comprometidas, la calidad del trabajo y los riesgos identificados.  
>
> Copia este archivo en `processes/sprint-evaluations/` y nómbralo usando el formato `sprint-[numero]-evaluation.md`. Completa todos los campos entre corchetes, enlaza las evidencias disponibles y elimina este bloque antes de aprobar el informe.  
>
> Este documento no reemplaza el Sprint Planning ni la Retrospectiva. El Planning define qué se hará y la Retrospectiva identifica mejoras del equipo; este informe registra los resultados reales del Sprint.
