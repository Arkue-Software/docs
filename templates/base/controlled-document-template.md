# Plantilla base de documento controlado

> **Instrucciones de uso - eliminar al crear un documento real:**  
> Esta es la plantilla base para los documentos controlados del proyecto RedVital. Se utiliza para crear nuevas plantillas o documentos que requieran control de versión, revisión y aprobación.  
>
> Copia este archivo en la carpeta correspondiente al tipo de documento que vas a crear. Reemplaza todos los campos entre corchetes y elimina este bloque antes de aprobar el documento.  
>
> No modifiques una versión aprobada directamente. Cuando sea necesario realizar un cambio, actualiza la versión, registra el cambio en el historial y solicita la revisión correspondiente.
