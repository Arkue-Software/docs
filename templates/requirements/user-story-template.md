# Historia de usuario - HU-XXX

> **Instrucciones de uso - eliminar al crear una historia real:**  
> Usa esta plantilla para redactar o revisar una historia de usuario antes de crearla en Jira.  
> La historia final debe registrarse en Jira y relacionarse con una épica.

| Campo | Contenido |
|---|---|
| Identificador | `HU-XXX` |
| Épica asociada | `[E-XX - Nombre de la épica]` |
| Clase | `Negocio / Técnica` |
| Prioridad | `Must / Should / Could` |
| Estimación | `[Puntos de historia]` |
| Módulo | `[Módulo funcional asociado]` |
| Ítem de Jira | `[RV-000]` |

## Enunciado

**Como** [tipo de usuario]  
**Quiero** [necesidad o acción]  
**Para** [beneficio o valor esperado].

## Criterios de aceptación

1. **Dado que** [contexto inicial], **cuando** [acción], **entonces** [resultado esperado].
2. **Dado que** [contexto inicial], **cuando** [acción], **entonces** [resultado esperado].
