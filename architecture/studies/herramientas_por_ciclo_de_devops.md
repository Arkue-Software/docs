# Herramientas Por Ciclo De Devops
## Planeación
Se definen los requerimientos, las historias de usuario y las prioridades de cada ciclo de trabajo. Su objetivo es alinear las necesidades del negocio con las tareas técnicas del equipo antes de escribir la primera línea de código.
- Jira 
- ClickUp
- Azure Devops
- Linear
- GitHub Projects
---
## Codificación
Comprende la escritura del código fuente, la realización de revisiones entre pares mediante _Pull Requests_ y la gestión de versiones en un repositorio centralizado, garantizando trazabilidad y calidad técnica.
- Visual Studio Code
- JetBrains IDEs
- Visual Studio
- Git
- GitHub
- GitLab
- BitBucket
---
## Construcción
Se encarga de compilar el código fuente, resolver las dependencias del proyecto y empaquetar el software en contenedores o artefactos ejecutables que sean reproducibles en cualquier entorno.
- Docker
- Maven
- Gradle
- CMake
- npm
---
## Pruebas
Ejecuta de manera automatizada pruebas unitarias, de integración y análisis estático de código para validar el comportamiento del sistema y asegurar que no se introduzcan errores ni vulnerabilidades antes de avanzar.
- SonarQube
- JUnit
- Selenium
- NUnit
- PyTest
- GoogleTest
---
## Integración y Entrega Continua
Consiste en la automatización del flujo de Integración Continua (CI), donde se verifica y empaqueta la versión final aprobada asegurando que cumpla con todos los criterios de calidad necesarios para su posterior entrega.
- Github Actions 
- GitLab CI/CD
- Jenkins
---
## Despliegue
Se realiza el aprovisionamiento de la infraestructura y el despliegue automatizado del paquete de software en los entornos correspondientes (demostración, _staging_ o producción) sin intervención manual.
- Terraform
- Ansible 
- Kubernetes 
- Helm
---
## Operación y Mantenimiento
Asegura el funcionamiento continuo de los entornos en ejecución mediante la gestión de servidores, el balanceo de carga, el escalado de recursos y el mantenimiento de configuraciones activas.
- Nginx 
- HAProxy 
- AWS
- Azure
- GCP 
- Istio 
- Linkerd
---
## Monitoreo
Recolecta métricas, eventos y registros (_logs_) en tiempo real para evaluar el rendimiento general del sistema, garantizar su observabilidad y diagnosticar anomalías proactivamente antes de que afecten a los usuarios.
- Prometheus + Grafana
- Google Analytics
